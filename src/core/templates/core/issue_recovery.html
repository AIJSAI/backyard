Get {{ target.display_name }} back in

Back to members

{% comment %} Plain words on purpose. The person reading this page is a relative who was made a yard admin last week, and what they need is what the link does, who may use it, and how long it lasts — not the word "token". {% endcomment %}

This makes a one-time link that lets {{ target.display_name }} choose a new password. Use it when they have forgotten theirs and have no email address on file, so the usual Forgot your password? cannot reach them.

Before you make it

  • Make sure you are really talking to {{ target.display_name }} — a phone call or a text to the number you already have for them, not a message from somewhere new.
  • Anyone who gets the link can set the password, so send it to them and nobody else.
  • It works once, and it stops working after two days.
  • Making a new one turns off any earlier link for {{ target.display_name }}.
  • When they use it, they are signed out everywhere else and sign back in with the new password.
