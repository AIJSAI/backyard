{% comment %} Love, without leaving the page. The form under every post works on its own: it POSTs to the same `react` route the thread page uses, the view toggles the reaction and sends the member back to the post they were looking at. That is the whole feature, and it ships whether or not this file runs — a reload on a hundred-post feed is simply a rough way to say one word. So this is an enhancement and nothing else. It answers the same route with the same form data, reads back who reacted (scoped by the view, never assembled here), and writes the button's pressed state and the reactor line in place. Anything that goes wrong — no fetch, an error status, a stale CSRF token, a dropped connection — falls through to `form.submit()`, which is the unenhanced path the page already had. Names are written with textContent, never innerHTML: a display name is a person's own text and this is the one place it would be re-parsed as markup. Inline with the response nonce, like `_localise_times.html` and the media picker: the policy is script-src 'self' 'nonce-...' with no 'unsafe-inline'. {% endcomment %}
